# Task Manager API Specification

## 1. Overview

The Task Manager API allows clients to create, retrieve, update, and delete tasks.

- **Base path:** `/api/v1`
- **Data format:** JSON (`application/json`)
- **ID format:** Positive integers generated by the server

### Task Object

| Field         | Type    | Description                                    |
| ------------- | ------- | ---------------------------------------------- |
| `id`          | Integer | Unique, server-generated ID                    |
| `title`       | String  | Required; must not be empty or whitespace-only |
| `description` | String  | Optional during creation; defaults to `""`     |
| `completed`   | Boolean | Defaults to `false` during creation            |

Example:

```json
{
  "id": 1,
  "title": "Learn Python",
  "description": "Practise functions and classes",
  "completed": false
}
```

## 2. Endpoints

### 2.1 List All Tasks

**Method:** `GET`

**Path:** `/api/v1/tasks`

**Description:** Returns all tasks or an empty array if none exist.

**Example request:**

```http
GET /api/v1/tasks
```

**Success response: `200 OK`**

```json
[
  {
    "id": 1,
    "title": "Learn Python",
    "description": "Practise functions and classes",
    "completed": false
  }
]
```

An empty collection returns `[]`.

**Error responses:**

- `500 Internal Server Error` — an unexpected server error prevents retrieval.

### 2.2 Get a Task by ID

**Method:** `GET`

**Path:** `/api/v1/tasks/{id}`

**Description:** Returns the task matching the supplied ID.

**Example request:**

```http
GET /api/v1/tasks/1
```

**Success response: `200 OK`**

```json
{
  "id": 1,
  "title": "Learn Python",
  "description": "Practise functions and classes",
  "completed": false
}
```

**Error responses:**

- `400 Bad Request` — the ID is not a positive integer.
- `404 Not Found` — no task exists with that ID.
- `500 Internal Server Error` — an unexpected server error prevents retrieval.

### 2.3 Create a Task

**Method:** `POST`

**Path:** `/api/v1/tasks`

**Description:** Creates a task. The title is required; the description and completion status are optional.

**Example request:**

```http
POST /api/v1/tasks
Content-Type: application/json
```

```json
{
  "title": "Learn Python",
  "description": "Practise functions and classes"
}
```

**Success response: `201 Created`**

```json
{
  "id": 1,
  "title": "Learn Python",
  "description": "Practise functions and classes",
  "completed": false
}
```

**Error responses:**

- `400 Bad Request` — the body is missing or malformed, the title is missing or invalid, or a field has an invalid type.
- `500 Internal Server Error` — an unexpected server error prevents creation.

### 2.4 Update a Task

**Method:** `PUT`

**Path:** `/api/v1/tasks/{id}`

**Description:** Replaces an existing task's editable fields. The request must include `title`, `description`, and `completed`. The ID comes from the path.

**Example request:**

```http
PUT /api/v1/tasks/1
Content-Type: application/json
```

```json
{
  "title": "Learn FastAPI",
  "description": "Build a REST API using Python",
  "completed": true
}
```

**Success response: `200 OK`**

```json
{
  "id": 1,
  "title": "Learn FastAPI",
  "description": "Build a REST API using Python",
  "completed": true
}
```

**Error responses:**

- `400 Bad Request` — the ID is invalid, the body is missing or malformed, a required field is missing, the title is invalid, or a field has an invalid type.
- `404 Not Found` — no task exists with that ID.
- `500 Internal Server Error` — an unexpected server error prevents updating.

### 2.5 Delete a Task

**Method:** `DELETE`

**Path:** `/api/v1/tasks/{id}`

**Description:** Permanently deletes the task matching the supplied ID.

**Example request:**

```http
DELETE /api/v1/tasks/1
```

**Success response: `204 No Content`**

No response body is returned.

**Error responses:**

- `400 Bad Request` — the ID is not a positive integer.
- `404 Not Found` — no task exists with that ID.
- `500 Internal Server Error` — an unexpected server error prevents deletion.

## 3. General Rules

1. All endpoints use the `/api/v1` base path.
2. Task IDs are positive integers generated by the server.
3. Titles must be strings containing at least one non-whitespace character.
4. Descriptions must be strings. Omitted descriptions default to `""` during creation.
5. `completed` must be a Boolean when supplied and defaults to `false` during creation.
6. `PUT` requests must include all editable fields: `title`, `description`, and `completed`.
7. Invalid requests return `400 Bad Request`; nonexistent tasks return `404 Not Found`; unexpected server failures return `500 Internal Server Error`.
8. Error responses use this JSON format:

```json
{
  "error": "Task with ID 99 not found"
}
```
